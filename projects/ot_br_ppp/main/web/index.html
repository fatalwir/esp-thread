Thread addresses

This node's active Thread dataset. Saving makes this node leave its network and join the one described here; other nodes are not changed. To join an existing network, paste the hex from ot dataset active -x on one of its border routers into "Dataset TLVs" and use "Apply TLVs".

Stored on the board and applied after a reboot. The defaults come from the build (network.defaults); a factory reset returns to them.

Running

Upload a build/esp_ot_br_ppp.bin. The board reboots into it and keeps it once the PPP link to the router comes up; if it resets before that, it goes back to the current firmware.
